# Giga Link · Web design proposals

Client review gallery containing the approved reference site and seven alternative
designs. Every version shares the same prices, coverage catalog, and lead form.

Run `npm ci` and `npm run dev` to work locally. Build with `npm run build`.
GitHub Actions publishes the static build to GitHub Pages from `main`.
Each proposal has a shareable URL using the `vista` query parameter.

Google Maps is optional. If enabling it, set the repository variable
`VITE_GOOGLE_MAPS_API_KEY` to a browser key restricted to the Pages site.
The public build can search through Photon without that variable.

## Presentation images

Generated with the built-in image generation tool and optimized as WebP.

- `public/propuestas/hogar.webp` — Candid editorial photography of a young adult woman and partner relaxing on a charcoal blue couch in a contemporary apartment in Tucumán, one using a laptop. - `public/propuestas/fibra.webp` — Macro photographic render of flowing fiber-optic strands sweeping from lower left into a bright bundle at right. Electric blue and periwinkle on nearly black navy, restrained glow, cinematic landscape. No text, icons, or logos.
